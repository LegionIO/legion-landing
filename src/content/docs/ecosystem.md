## Code you can inspect

Extensions are separate gems. The catalog below uses the repository's generated metadata, checked against the pinned public capability catalog. Each gem opens a reference page with its runners and functions.

A catalog entry establishes that code was extracted into this snapshot. It does not establish configuration, credentials, runtime exposure, or operational maturity. Agentic entries remain labeled experimental.
